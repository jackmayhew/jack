# Jack's Portfolio

My personal portfolio. Mostly projects, a bit about me, and the occasional update.

Built with Nuxt 4, Tailwind CSS, and GSAP. Hosted on Cloudflare Pages.

[Check it out](https://www.jackmayhew.com/)

## Local Development

Install dependencies:

```bash
pnpm install
```

Set up the environment file:

```bash
cp .env.example .env
```

Start the development server:

```bash
pnpm dev
```
